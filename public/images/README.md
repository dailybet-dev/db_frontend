# DailyBet image assets

Upload the DailyBet logo files and other static images to this folder.

Suggested filenames:
- `dailybet-logo.png` — full wordmark
- `dailybet-logo.svg` — vector wordmark, if available
- `dailybet-icon.png` — standalone dB icon
- `dailybet-icon.svg` — vector icon, if available

These files will be publicly served from `/images/<filename>` (for example, `/images/dailybet-logo.png`). Keep filenames lowercase and avoid spaces.

**Favicon:** For the standard browser favicon, place `favicon.ico` directly in `public/favicon.ico` (not in this `images` folder). You can also use Next.js app icon conventions if preferred.
